Installation du Runtime Boomi

Procédure d'installation du runtime Boomi (Atom) en tant que service systemd sur Linux — environnement 01a_ONPREM_RCT.

Avant de commencer

📋 Prérequis

🔑
Account ID Ex : moncompte-XXXXXX
Settings › Account Information
🪙
Auth Token Format : BOOMI_TOKEN.email:xxxx
Settings › API Tokens
☕
Java (JRE 11+) Requis par le runtime Boomi.
java -version pour vérifier.
🐧
Linux 64-bit + sudo Ubuntu 20.04+ recommandé.
jq et wget requis.

Étapes d'installation

1

Créer le groupe et l'utilisateur de service

sudo requis

L'Atom tourne sous un compte système dédié sans shell interactif. Il ne doit pas tourner sous ton propre compte.

Création du groupe et du user
sudo groupadd boomigroup
sudo useradd -r -m -s /bin/false -g boomigroup -c "Boomi service user" boomiuser

Ajoute les droits sudo limités pour que le service puisse gérer lui-même son démarrage/arrêt :

Droits systemctl sans mot de passe
cat <<EOF | sudo tee /etc/sudoers.d/boomi
boomiuser ALL=NOPASSWD: /bin/systemctl start boomi-LOCAL_LIN_RUN_RCT_01.service
boomiuser ALL=NOPASSWD: /bin/systemctl stop boomi-LOCAL_LIN_RUN_RCT_01.service
boomiuser ALL=NOPASSWD: /bin/systemctl restart boomi-LOCAL_LIN_RUN_RCT_01.service
boomiuser ALL=NOPASSWD: /bin/systemctl status boomi-LOCAL_LIN_RUN_RCT_01.service
EOF
sudo chmod 0440 /etc/sudoers.d/boomi
ℹ️
Le wildcard boomi-*.service est à éviter dans sudoers — le * y correspond à n'importe quelle chaîne y compris les /, ce qui génère des warnings de sécurité. Toujours utiliser le nom exact du service.
⚠️
Si tu utilises un user existant, le script de création est ignoré et les droits sudoers ne sont pas ajoutés. Toujours créer un user dédié.
2

Télécharger l'installateur Boomi

wget

L'installateur officiel Boomi est téléchargé depuis la plateforme. Il sera utilisé à l'étape 4.

Téléchargement
wget https://platform.gb.boomi.com/atom/atom_install64.sh
chmod +x ./atom_install64.sh
🔴
Erreur 407 Proxy Authentication Required — rencontrée en recette lors du téléchargement du JRE par le script d'installation.
3

Obtenir le token d'installation

Console Boomi · valable 60 min

Le token d'installation est généré depuis la console Boomi. Il lie l'Atom installé à ton compte et à l'environnement cible.

Console Boomi
Manage › Atom Management
→
+ Add Atom
Type : Atom
→
Copier le token
valable 60 min
  1. Dans la console Boomi : Manage › Atom Management
  2. Cliquer + New Atom
  3. Sélectionner l'environnement 01a_ONPREM_RCT
  4. Le token s'affiche — le copier immédiatement
Exemple de token généré — recette
atom-xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
⚠️
Le token expire après 60 minutes. Ne pas le générer trop tôt avant de lancer l'installation. Si expiré, en générer un nouveau depuis la même interface.
4

Installer l'Atom

atom_install64.sh

Créer le dossier d'installation puis lancer l'installateur en mode interactif. L'installateur guide à travers chaque paramètre.

Lancement
sudo ./atom_install64.sh

L'installateur demande chaque paramètre interactivement. Valeurs saisies en recette :

Réponses aux prompts de l'installateur
Atom name          : LOCAL_LIN_RUN_RCT_01
Install token      : atom-xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
Install directory  : /int-atom/Boomi_AtomSphere/Atom/Atom_LOCAL_LIN_RUN_RCT_01/
Proxy host         : proxy.host
Proxy port         : 8080
Proxy user         : user
Proxy password     : password

Dossier créé : /int-atom/Boomi_AtomSphere/Atom/Atom_LOCAL_LIN_RUN_RCT_01/

✅
À la fin de l'install, l'Atom apparaît Online dans la console Boomi sous Atom Management (environnement 01a_ONPREM_RCT).

Copier ensuite les propriétés de purge dans le dossier de l'Atom :

Propriétés de purge (container.properties)
cat <<EOF >> /int-atom/Boomi_AtomSphere/Atom/Atom_LOCAL_LIN_RUN_RCT_01/conf/container.properties
com.boomi.container.dataDirNestLevel=2
com.boomi.container.executionDirNestLevel=2
com.boomi.container.component.purgeDays=15
com.boomi.container.data.purgeDays=15
com.boomi.container.logs.purgeDays=15
com.boomi.container.purge.numPurgeThreads=2
com.boomi.container.temp.purgeDays=7
EOF
5

Créer le service systemd

sudo requis

5a — Transfert de propriété du dossier d'installation à l'utilisateur de service :

Propriétaire des fichiers Atom
sudo chown -R boomiuser:boomigroup /int-atom

5b — Fichier de service dans /etc/systemd/system/ :

Création du fichier .service
cat <<EOF | sudo tee /etc/systemd/system/boomi-LOCAL_LIN_RUN_RCT_01.service
[Unit]
Description=Boomi LOCAL_LIN_RUN_RCT_01
After=network.target

[Service]
Type=forking
User=boomiuser
Group=boomigroup
Restart=always
ExecStart=/int-atom/Boomi_AtomSphere/Atom/Atom_LOCAL_LIN_RUN_RCT_01/bin/atom start
ExecStop=/int-atom/Boomi_AtomSphere/Atom/Atom_LOCAL_LIN_RUN_RCT_01/bin/atom stop
ExecReload=/int-atom/Boomi_AtomSphere/Atom/Atom_LOCAL_LIN_RUN_RCT_01/bin/atom restart

[Install]
WantedBy=multi-user.target
EOF

5c — Activation et démarrage :

Activation au boot + démarrage immédiat
sudo systemctl daemon-reload
sudo systemctl enable boomi-LOCAL_LIN_RUN_RCT_01.service
sudo systemctl start  boomi-LOCAL_LIN_RUN_RCT_01.service

Vérification :

Statut du service
sudo systemctl status boomi-LOCAL_LIN_RUN_RCT_01.service
✅
Tu dois voir Active: active (running). L'Atom reste Online dans la console Boomi dans les 30-60 secondes.

Points d'attention

QuoiPourquoi
atomName — caractères valides Systemd n'accepte que lettres, chiffres, - _ .. Un espace ou # provoque Invalid unit name au systemctl enable.
chown avant ou après l'install Faire chown -R boomiuser:boomigroup /int-atom après l'installation. Si fait avant, les fichiers créés par l'installateur appartiennent à root et l'Atom ne peut pas écrire ses logs.
Token d'installation — 60 min Si l'install échoue ou traîne, le token est expiré. Relancer l'étape 3 pour en obtenir un nouveau.
Token d'installation — console Boomi Généré depuis Manage › Atom Management › New Atom. Format : atom-xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx. Valable 60 min — en générer un nouveau si l'install traîne.

Dépannage

  • 🔴
    Invalid unit name Caractère interdit dans atomName. Renommer l'Atom (lettres, chiffres, - _ . seulement), recréer le fichier service.
  • 🔴
    Erreur 407 Proxy Authentication Required Rencontré en recette lors du téléchargement du JRE par le script d'installation. Configurer http_proxy / https_proxy avant de lancer l'installateur, ou passer -VproxyHost, -VproxyPort, -VproxyUser, -VproxyPassword en arguments.
  • 🔴
    Permission denied au démarrage chown -R boomiuser:boomigroup /int-atom n'a pas été fait après l'installation. Le relancer puis systemctl restart.
  • 🟡
    Atom absent de la console Boomi après install Token expiré (60 min). Générer un nouveau token depuis Manage › Atom Management › New Atom et relancer l'étape 4. Vérifier aussi que Java est accessible : java -version.
  • 🟡
    Consulter les logs du service journalctl -u boomi-LOCAL_LIN_RUN_RCT_01.service -n 50 --no-pager
